# Run local multi-agent work sessions with Orkas

Use Orkas to coordinate local-first multi-agent desktop work sessions across built-in specialist agents and installed coding CLIs such as Claude Code, Codex, OpenCode, OpenClaw, and Hermes.

## Prerequisites

Orkas desktop app, local workspace access, bring-your-own model API keys, optional installed coding CLIs such as Claude Code, Codex, OpenCode, OpenClaw, or Hermes

## Installation

Install or set up from the source-backed instructions:

Download the Orkas desktop app for macOS, Windows, or Linux from the upstream project site or GitHub releases, configure model provider keys, then use the Commander to plan and delegate work across built-in agents and optional local CLI agents.
