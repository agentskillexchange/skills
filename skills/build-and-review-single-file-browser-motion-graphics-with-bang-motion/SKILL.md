# Build and review single-file browser motion graphics with Bang Motion

Turn a brand brief into an approved motion concept and one playable index.html, then scrub key moments and revise the same timeline before handoff.

## Prerequisites

A skills-aware coding agent; Git; modern browser; internet for CDN dependencies; optional Node.js and Puppeteer for frame capture; optional ffmpeg for MP4 encoding

## Installation

Install or set up from the source-backed instructions:

Clone https://github.com/bangtutorial/bang-motion and reference its SKILL.md from the agent configuration, keeping references/, assets/ and scripts/ available. Claude Code alternatively supports /plugin marketplace add bangtutorial/bang-motion followed by /plugin install bang-motion@bang-motion. Install only one copy. Request an opener, bumper or kinetic-typography sequence with a brief and duration. The delivered HTML needs a modern browser; Node.js is optional for automated snapshots.
