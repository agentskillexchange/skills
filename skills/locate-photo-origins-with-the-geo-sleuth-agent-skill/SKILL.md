# Locate photo origins with the Geo Sleuth agent skill

Install a cross-runtime agent skill that geolocates photos using EXIF, image preparation, OCR, OpenStreetMap geometry, elevation skylines, satellite imagery, and browser-backed reverse image search.

## Prerequisites

Agent runtime that reads SKILL.md, Node/npm skills CLI, Python 3.10+, uv, curl, Google Chrome or Playwright Chromium

## Installation

Install or set up from the source-backed instructions:

Install with `npx skills add Oldcircle/geo-sleuth -g -a claude-code -a codex -a cursor -a gemini-cli -a opencode -a github-copilot -y`, then ask the agent to run the installed `scripts/doctor.py` checks and address missing dependencies before analyzing photos.
