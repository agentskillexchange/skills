# Search and fetch biomedical literature through MCP with PubMed MCP Server

Connect an MCP-capable agent to PubMed, Europe PMC, PMC full text, Unpaywall, citations, and MeSH tools for supervised biomedical literature workflows.

## Prerequisites

An MCP-compatible client, Node.js/npm for local stdio use or access to the hosted Streamable HTTP MCP endpoint, and network access to PubMed, Europe PMC, PMC, Unpaywall, and related biomedical literature services.

## Installation

Install or set up from the source-backed instructions:

For local stdio use, add an MCP server entry that runs npx -y @cyanheads/pubmed-mcp-server. For hosted use, configure the MCP client for Streamable HTTP at https://pubmed.caseyjhand.com/mcp. Review the upstream README for transport, auth, and storage options before enabling it in shared workflows.
