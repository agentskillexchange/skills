# Run IDE-wired terminal coding-agent workflows with Oh My Pi

Use Oh My Pi when an operator wants a local terminal coding agent with IDE-grade context, built-in file tools, LSP-aware edits, debugger access, subagents, memory, and multi-provider model routing.

## Prerequisites

Oh My Pi CLI, shell access, model provider credentials, optional LSP and debugger adapters

## Installation

Install or set up from the source-backed instructions:

Install with Homebrew (brew install can1357/tap/omp), Bun (bun install -g @oh-my-pi/pi-coding-agent), Nix, or the documented platform installer from https://omp.sh/install. Then run omp from a repository workspace and configure provider credentials as needed.
