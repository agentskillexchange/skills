# Draft, review and export code-driven pixel effects with Pixelfx

Find or draft a pixel effect, inspect rendered contact sheets, refine its motion and export a transparent sprite sheet with timing and pivot metadata.

## Prerequisites

Claude Code; Git; Node.js 18+; an image inspection tool; optional ffmpeg for animated previews

## Installation

Install or set up from the source-backed instructions:

In Claude Code run /plugin marketplace add patch-gg/pixelfx, then /plugin install pixelfx@pixelfx. Clone https://github.com/patch-gg/pixelfx and work from its checkout. Alternatively copy skills/pixelfx into ~/.claude/skills/. Core rendering tools need Node.js 18+ and no dependency installation. Verify with node tools/render.mjs fire/torch and inspect records/fire/torch/contact.png.
