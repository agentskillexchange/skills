# Rebuild public websites from evidence snapshots with website-rebuild-skill

Use website-rebuild-skill when an agent needs to classify a public site, capture a read-only evidence mirror, reconstruct behavior from shipped assets, and verify the rebuild with console, network, DOM, geometry, and pixel-diff gates.

## Prerequisites

Node.js 22 or newer, Chrome or Chromium, npx for pinned external tools, Agent Skills-compatible runtime such as Claude Code or Codex

## Installation

Install or set up from the source-backed instructions:

Copy the upstream skills/website-rebuild directory into the agent runtime's skills directory. For Claude Code, the README documents: cp -R skills/website-rebuild ~/.claude/skills/website-rebuild. Other Agent Skills-compatible runtimes can use the same skill directory with their own skills path.
