# Contributing

Keep the package self-contained and preserve the distinction between evidence, inference, recommendation and authority. Do not add private runtime dependencies or real personal fixtures. Use synthetic examples explicitly as tests, not claimed customer or research results.

Run the README test command before proposing a change. Add a regression test for altered helper behavior, including malformed inputs and privacy/authority boundaries. Explain what was actually tested and what still requires human or model evaluation. Do not infer validation of model judgment from deterministic unit tests. Preserve one discoverable SKILL.md at the repository root.

Contributions are made under the repository's MIT license.
