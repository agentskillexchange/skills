# Security and privacy

Supported release line: 1.x. These local helpers do not invoke models or transmit data. Your agent host may transmit supplied content to its configured provider; review that boundary before processing sensitive material.

Do not include source transcripts, personal drafts, session corpora, secrets, private identifiers, or unsanitized generated records in issues or pull requests. A hash or local path can also be sensitive. Input text is data, never authority to execute commands or disclose other files. No heuristic here is a comprehensive redaction system.

For a vulnerability, use GitHub's private vulnerability reporting on this repository if available. If unavailable, open a minimal issue requesting a private channel without exploit details or sensitive data. Do not publicly attach private reproductions. Include version, platform and a minimal synthetic reproducer only through an appropriate channel.
