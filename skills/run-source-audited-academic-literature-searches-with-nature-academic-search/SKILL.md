# Run source-audited academic literature searches with Nature Academic Search

Use Nature Academic Search to plan, deduplicate, verify, graph, and export academic literature searches across multiple scholarly sources.

## Prerequisites

nature-academic-search CLI or MCP server, uv or compatible Python tool installer, PubMed contact email, optional Codex plugin, Claude Code plugin, or DeepSeek Harness bundle

## Installation

Install or set up from the source-backed instructions:

For local CLI/MCP use, run uv tool install nature-academic-search, set PUBMED_EMAIL, then run nature-academic-search install --client both --email researcher@example.com and nature-academic-search preflight. Codex and Claude Code plugin installation paths are documented in the upstream README.
