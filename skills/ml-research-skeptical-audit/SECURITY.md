# Security policy

Version 1.0.x is the supported release line. Skill instructions are not a sandbox and cannot override host permissions or the user's scope.

Do not put secrets, private source excerpts, personal records, tracker exports, or exploit-ready details into public issues. Use GitHub's private vulnerability reporting feature for AntreasAntoniou/ml-research-skeptical-audit if it is enabled. If no private reporting route is available, open a minimal public issue requesting a private channel without disclosing the vulnerability or sensitive material.

Report the affected version, impact, a minimal synthetic reproduction, and mitigation suggestions. No response-time or remediation guarantee is implied. For accidental exposure, stop distribution and rotate affected credentials through the owner's approved process; deleting a file alone does not revoke a secret.
