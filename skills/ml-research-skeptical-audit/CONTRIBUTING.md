# Contributing

Keep this package self-contained and focused on its named method. Propose substantial scope changes before implementation. Preserve the distinction between local preparation, verified behavior, and external execution.

Use synthetic fixtures only; never submit private paths, user records, credentials, proprietary examples, or copied Git history. Add behavioral tests for helper changes and run the documented tests. Check that exactly one SKILL.md is discoverable and every referenced bundled file exists. Run the official skill quick validator when available; record what was and was not checked.

For instruction changes, include a realistic request showing the decision improved and any authorization boundary involved. For script changes, preserve read-only defaults and bounded failure behavior. Submitted contributions are under this repository's MIT license; retain applicable notices.
