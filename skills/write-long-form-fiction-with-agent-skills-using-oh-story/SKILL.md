# Write long-form fiction with agent skills using Oh Story

Use Oh Story when a coding agent should run a structured fiction-writing workflow with project files, story state, outlines, drafting gates, continuity tracking, style cleanup, and cover-generation steps.

## Prerequisites

Oh Story skills, npx skills installer, and a supported file-aware coding agent such as Claude Code, Codex CLI, OpenCode, OpenClaw, Google Antigravity, ZCode, or Reasonix

## Installation

Install or set up from the source-backed instructions:

Run `npx skills add zenstory-ai/oh-story-claudecode -y -g`, then run `/story-setup` in the writing project. In Codex-style hosts, invoke setup as `$story-setup` where slash commands are not supported.
