# Prepare Indian ITR filings with deterministic tax checks through itr-wala

Use itr-wala when an agent needs a review-first workflow for reading Indian tax documents, running deterministic AY 2026-27 tax calculations, comparing regimes, and guiding the user up to the pay, submit, and e-verify steps.

## Prerequisites

Python 3, Claude Code or Codex or Gemini-compatible skill runtime, local checkout of itr-wala, user-provided Indian tax documents

## Installation

Install or set up from the source-backed instructions:

Review the repository, then run: git clone https://github.com/karanb192/itr-wala.git && cd itr-wala && ./install.sh. For scoped local use, run ./install.sh --here from the folder that contains the user's tax documents. The README also documents Claude Code plugin, Codex plugin, and skills.sh installation paths.
