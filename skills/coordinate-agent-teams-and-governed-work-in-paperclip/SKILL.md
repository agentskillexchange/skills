# Coordinate agent teams and governed work in Paperclip

Use Paperclip as a self-hosted control plane for assigning goals, tasks, budgets, approvals, routines, and run history across multiple AI agents.

## Prerequisites

Node.js 24 or later; Paperclip CLI package; local machine or server/VPS deployment target; selected agent runtimes such as OpenClaw, Claude Code, Codex, Cursor, Gemini CLI, OpenCode, process/HTTP agents, or MCP-backed adapters

## Installation

Install or set up from the source-backed instructions:

Run npx paperclipai onboard --yes for the standard local setup, then complete the browser onboarding flow to create the first company, agent, and task. For team or remote access, follow the Server / VPS installation guide and configure database, storage, HTTPS, identity, adapters, and secrets before assigning agent work.
