# Turn single research papers into Obsidian notes with DeepPaperNote

Run a source-grounded agent workflow that reads one paper deeply and saves a durable Obsidian-style research note.

## Prerequisites

One supported agent runtime such as Claude Code, Codex, Cursor, Copilot, or Gemini CLI; Python 3.10+; PyMuPDF; optional Zotero Local API, Semantic Scholar API, OCR tooling, and an Obsidian vault

## Installation

Install or set up from the source-backed instructions:

Run npx skills add 917Dhj/DeepPaperNote, choose the deeppapernote skill, install the PDF dependency with python3 -m pip install PyMuPDF, then provide a paper title, DOI, URL, arXiv ID, Zotero item, or local PDF and ask the agent to generate a deep-reading note.
