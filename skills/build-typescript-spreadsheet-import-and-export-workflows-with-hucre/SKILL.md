# Build TypeScript spreadsheet import and export workflows with hucre

Use hucre when a coding agent needs to add zero-dependency XLSX, CSV, ODS, JSON, NDJSON, or XML spreadsheet parsing and writing to TypeScript or edge-runtime projects.

## Prerequisites

Node.js or a TypeScript-compatible runtime and the hucre npm package

## Installation

Install or set up from the source-backed instructions:

Install with `npm install hucre`, then import only the needed modules such as `hucre/xlsx`, `hucre/csv`, or `hucre/ods` and wire the read/write functions into the spreadsheet ingestion or export path.
