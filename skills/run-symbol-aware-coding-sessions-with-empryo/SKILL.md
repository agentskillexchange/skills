# Run symbol-aware coding sessions with Empryo

Use Empryo when a coding agent should map symbols, blast radius, and dependencies before making AST-backed edits across a repository.

## Prerequisites

Empryo desktop app or CLI, local repository, model API key or local Ollama/LM Studio-compatible model, optional MCP servers

## Installation

Install or set up from the source-backed instructions:

Install Empryo from the official download page at https://empryo.com/download using the platform installer for macOS, Linux, or Windows. Configure a model provider key or local Ollama/LM Studio-compatible model, then run Empryo inside the target repository.
