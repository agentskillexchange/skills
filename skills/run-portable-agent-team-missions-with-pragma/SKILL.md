# Run portable agent-team missions with Pragma

Use Pragma when an operator wants to define reusable agent teams, flows, memory, permissions, and human checkpoints once, then run the same mission through Desktop, CLI, Codex, Claude Code, or an embedded SDK host.

## Prerequisites

Pragma Desktop or @pqpo/pragma CLI, configured model provider or local agent runtime, workspace permissions as needed

## Installation

Install or set up from the source-backed instructions:

For Desktop, download the macOS package from GitHub Releases. For CLI/runtime examples, install Node.js 22 and pnpm 10.12.1, clone https://github.com/pqpo/pragma, run pnpm install --frozen-lockfile, then use the documented @pragma examples or @pqpo/pragma CLI.
