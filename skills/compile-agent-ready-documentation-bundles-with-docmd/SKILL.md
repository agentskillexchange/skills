# Compile agent-ready documentation bundles with docmd

Use docmd when a project needs one Markdown documentation source to produce a site, search index, llms.txt, MCP endpoints, and structured knowledge bundles for agents.

## Prerequisites

Node.js 18+, Markdown documentation source, optional MCP-capable coding agent or RAG pipeline consumer

## Installation

Install or set up from the source-backed instructions:

Run npx @docmd/core dev in a documentation folder for local preview, or install @docmd/core globally and use docmd dev or docmd build. Review the generated site, search index, llms.txt, MCP endpoints, and knowledge bundle outputs before deployment.
