# Create and review pixel art in Aseprite with AI Artist

Connect an agent to an open Aseprite window so it can brief, draw, animate, critique, fix, and export pixel art with undoable steps.

## Prerequisites

Aseprite 1.3+, Node.js 22.6+, npm, and a supported agent such as Claude Code, Codex CLI, Gemini CLI, Cursor, VS Code, Windsurf, or omp.

## Installation

Install or set up from the source-backed instructions:

Run `npx @pebbly/aseprite-ai-artist install-extension`, reopen Aseprite, then install the agent integration. For Codex, Gemini, Cursor, VS Code, or Windsurf run `npx @pebbly/aseprite-ai-artist install codex` or the matching target. Restart the agent and verify with `npx @pebbly/aseprite-ai-artist doctor`.
