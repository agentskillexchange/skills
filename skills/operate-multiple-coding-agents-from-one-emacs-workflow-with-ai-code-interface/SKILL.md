# Operate multiple coding agents from one Emacs workflow with AI Code Interface

Give Emacs users one workflow layer for Codex, Claude Code, Gemini CLI, Cursor CLI, opencode, and other coding-agent backends.

## Prerequisites

Emacs 29.1+, MELPA or straight.el, one supported coding-agent CLI, vterm/eat/ghostty or another configured terminal backend

## Installation

Install or set up from the source-backed instructions:

Enable MELPA, refresh package contents, install the ai-code package with M-x package-install, configure a backend such as (ai-code-set-backend 'codex), and bind ai-code-menu, for example to C-c a.
