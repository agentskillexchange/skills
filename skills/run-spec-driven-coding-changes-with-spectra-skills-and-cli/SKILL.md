# Run spec-driven coding changes with Spectra skills and CLI

Manage proposal, implementation, verification, review, audit, drift, archive, and commit steps through Spectra's agent skills and CLI-backed spec workflow.

## Prerequisites

Node.js 22.14+ for the spxa CLI, optional Spectra desktop app, Codex, Claude Code, Cursor, GitHub Copilot, Antigravity, or JetBrains Junie

## Installation

Install or set up from the source-backed instructions:

Install the CLI with `npm install -g @kaochenlong/spxa`, run `spxa init` in the target repository, then invoke the documented agent skills such as `$spectra-propose`, `$spectra-apply`, `$spectra-verify`, `$spectra-review`, `$spectra-audit`, `$spectra-drift`, `$spectra-archive`, or `$spectra-commit`.
