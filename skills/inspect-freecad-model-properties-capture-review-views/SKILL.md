# Inspect FreeCAD model properties and capture review views

Inspect an open FreeCAD document through MCP, collect object properties and capture oriented views for a model-review evidence handoff.

## Prerequisites

FreeCAD; FreeCADMCP addon; uv/uvx; freecad-mcp MCP server; MCP client

## Installation

Install or set up from the source-backed instructions:

Clone the source repository at the documented commit. Copy addon/FreeCADMCP into the platform-specific FreeCAD addon directory using docs/installation.md. Restart FreeCAD, select MCP Addon and start its RPC server. Configure the MCP client command uvx with args ["freecad-mcp"]. Match installed server/addon versions and schemas to the source documentation before use. Source commit: 5014bd9d538b8d09e11201e219cfe291ebca7b4e.
