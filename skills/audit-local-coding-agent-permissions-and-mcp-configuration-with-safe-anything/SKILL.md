# Audit local coding-agent permissions and MCP configuration with Safe Anything

Review a selected project’s agent permissions, MCP launch pins, credentials and hooks with an offline scan and a file-and-line configuration risk checklist.

## Prerequisites

Safe Anything CLI 1.0.2; read access to explicitly authorized project and agent configuration files; JSON-capable agent runtime

## Installation

Install or set up from the source-backed instructions:

Install the reviewed version with cargo install safe-anything --version 1.0.2 --locked, or use npx safe-anything@1.0.2. Verify the version. Run safe-anything /absolute/project/path --offline --json. Installation requires network access; offline applies to scanning. No installation or scanner execution occurred during intake.
