# Manage Cross-Agent Skill Libraries with Skills Manager

Use Skills Manager when an operator needs one auditable library for installing, inspecting, tagging, syncing, backing up, and deploying agent skills across many coding tools.

## Prerequisites

Skills Manager desktop app or repository CLI; Node.js 18+ and Rust/Tauri prerequisites for source builds; Git when using repository-backed backup or Git skill imports; one or more supported agent skill directories.

## Installation

Install or set up from the source-backed instructions:

Use the official release/app path documented at https://skillsmanager.dev, or build from source with npm install and npm run tauri:build. For CLI workflows from the source tree, use npm run cli -- skills list, npm run cli -- skills install , and npm run cli -- skills deploy --agent .
