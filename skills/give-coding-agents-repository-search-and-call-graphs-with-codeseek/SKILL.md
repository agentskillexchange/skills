# Give coding agents repository search and call graphs with CodeSeek

Install CodeSeek to index a repository, expose semantic search and call-graph queries, and register MCP tools for Claude Code or Codex coding agents.

## Prerequisites

Node.js/npm, CodeSeek CLI, MCP-capable agent runtime, embedding model configured during setup

## Installation

Install or set up from the source-backed instructions:

npm install -g codeseek && codeseek install
