# Run method-guided coding sessions with Loushang

Use Loushang to run recoverable coding-agent sessions with model routing, durable context, tool governance, methods, stages, and traceable delivery artifacts.

## Prerequisites

Python, uv, git, configured model providers, and the Loushang CLI.

## Installation

Install or set up from the source-backed instructions:

Clone the repository, create a virtual environment with uv venv .venv, activate it, then run uv pip install -e ".[dev]". Check setup with loushang --help, loushang --list-models, and loushang --list-commands.
