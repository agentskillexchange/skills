# Delegate fast Gemini staffers from Codex and Claude Code with agy-staff

Use agy-staff to give Codex, Claude Code, and Pi reusable Antigravity CLI staff personas for quick research, review, implementation, and second-opinion tasks.

## Prerequisites

Google Antigravity CLI, Codex or Claude Code, and the agy-staff companion prompts/personas.

## Installation

Install or set up from the source-backed instructions:

Follow the upstream install section for the target host agent, then restart or reload Claude Code or Codex. Smoke test with /agy:ask reply with OK in Claude Code or $agy:ask reply with OK in Codex before delegating tool-using staffer, researcher, reviewer, or implementer work.
