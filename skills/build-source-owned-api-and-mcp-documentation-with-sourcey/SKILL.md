# Build source-owned API and MCP documentation with Sourcey

Use Sourcey to turn OpenAPI, MCP, Doxygen, godoc, rustdoc, MkDocs, and Markdown sources into static documentation, search, code samples, changelogs, roadmaps, and LLM context exports.

## Prerequisites

Sourcey CLI, Node.js 20 or newer, and repository-owned OpenAPI, MCP, Doxygen, godoc, rustdoc, MkDocs, or Markdown documentation sources.

## Installation

Install or set up from the source-backed instructions:

Install with npm install -g sourcey, brew tap sourcey/tap && brew install sourcey, docker run -v "$PWD":/docs sourcey/sourcey, or nix run github:sourcey/sourcey. Start a project with sourcey init, preview with sourcey dev, and build static output with sourcey build.
