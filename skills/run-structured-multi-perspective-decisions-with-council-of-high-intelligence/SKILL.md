# Run structured multi-perspective decisions with Council of High Intelligence

Use Council of High Intelligence when an agent should convene a structured panel, force disagreement, and return a decision with dissent, kill criteria, and next actions.

## Prerequisites

Council of High Intelligence plugin or cloned repository, one supported agent host such as Claude Code, Codex, Gemini CLI, or OpenCode, and optional model/provider routing configuration

## Installation

Install or set up from the source-backed instructions:

In Claude Code, run /plugin marketplace add 0xNyk/council-of-high-intelligence and /plugin install council@council-of-high-intelligence. For Codex, Gemini CLI, or OpenCode, clone the repository and run ./install.sh with the matching --codex-only, --gemini-only, or --opencode-only flag, then restart the target client.
