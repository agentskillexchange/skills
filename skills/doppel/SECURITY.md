# Security and privacy

Voice corpora can contain personal data, confidential facts, and distinctive phrases. Keep all real sources, manifests, context packs, profiles, and drafts outside version control. The repository's ignore rules cover the recommended local filenames, but maintainers must still inspect staged files before every commit.

Do not use this project to impersonate a third party, evade attribution controls, or publish text without the subject's review. A manifest is a local technical control, not proof of legal consent.

Report a vulnerability privately through GitHub Security Advisories for this repository. Do not include a real corpus, manifest, profile, or draft in the report; provide a minimal synthetic reproduction instead.
