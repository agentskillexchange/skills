# Contributing

Contributions are welcome when they preserve the consent-first model.

1. Use only neutral synthetic fixtures in tests, issues, pull requests, and documentation.
2. Do not contribute a real person's corpus, profile, private path, or generated imitation.
3. Keep the runtime dependency-free unless a dependency has a clear safety or correctness benefit.
4. Run `python3 -m unittest discover -s tests -v` and `python3 scripts/validate_package.py`.
5. Explain any change to consent, provenance, attribution, or publication boundaries in the pull request.

By contributing, you agree that your contribution is licensed under the MIT License.
