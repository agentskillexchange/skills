# Triage Rhino Model Clashes with Object-Pair Measurements and Viewport Evidence

Inspect a pair of Rhino objects, distinguish exact clash results from bounding-box approximations, and return measurements with viewport evidence.

## Prerequisites

Rhino 8.20+ on Windows or macOS; .NET 8; RhinoMCP Rhino plugin; uv/uvx; MCP client

## Installation

Install or set up from the source-backed instructions:

Install rhinomcp through Rhino Tools > Package Manager and restart Rhino. Ensure Rhino 8.20+ runs on .NET 8. Configure one local MCP client with command uvx, args ["rhinomcp@latest"], and RHINO_MCP_HOST=127.0.0.1. Open the model and run mcpstart once per Rhino session. Run only one RhinoMCP server at a time.
