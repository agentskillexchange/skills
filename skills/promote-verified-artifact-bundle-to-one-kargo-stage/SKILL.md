# Promote a verified artifact bundle to one Kargo Stage

Check an exact Freight bundle against Stage eligibility, submit an authorized Kargo promotion and report deployment and verification evidence.

## Prerequisites

Kargo CLI; existing Kargo control plane and project; authorized operator context

## Installation

Install or set up from the source-backed instructions:

Use an existing Kargo installation. Download the CLI for your OS and architecture from the control plane UI CLI tab to match its API server. Rename it to kargo (kargo.exe on Windows), make it executable where required and place it on PATH. Authenticate using your deployment-approved method and verify access to the named project. See https://docs.kargo.io/user-guide/cli/installation/ .
