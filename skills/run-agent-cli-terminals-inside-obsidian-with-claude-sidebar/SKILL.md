# Run agent CLI terminals inside Obsidian with Claude Sidebar

Use Claude Sidebar when an operator wants Claude Code, Codex, or another agent CLI available as terminal tabs inside an Obsidian vault with file and folder context.

## Prerequisites

Obsidian desktop, Python 3, an installed agent CLI such as Claude Code, Codex, Grok Build, OpenCode, Gemini, Kimi Code, GitHub Copilot, Cursor Agent, or Pi, and pywinpty on Windows when using native Windows terminal support
