# Control coding-agent terminals remotely with 9Remote

Run and supervise Claude Code, Codex, Gemini CLI, and other terminal agents from a browser, desktop app, tablet, or phone with paired remote terminal, file, preview, and approval-oriented access.

## Prerequisites

Node.js/npm or the 9Remote desktop host, a web/mobile/desktop 9Remote client, and local coding-agent CLIs such as Claude Code, Codex, or Gemini CLI

## Installation

Install or set up from the source-backed instructions:

Install the host with npm install -g 9remote and run 9remote, or use the signed desktop release. Pair a browser, phone, tablet, or desktop client using the QR/link flow, approve the device on the host, then launch the desired coding-agent CLI inside a 9Remote terminal.
