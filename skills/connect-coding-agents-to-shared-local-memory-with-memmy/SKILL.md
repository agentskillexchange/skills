# Connect coding agents to shared local memory with Memmy

Use Memmy when Claude Code, Codex, OpenClaw, Cursor, or another local agent needs one controlled local memory service that persists context across tools and sessions.

## Prerequisites

Memmy desktop app or memmy CLI, memmy-memory CLI, Node.js for CLI/TUI workflows, supported local agent such as Claude Code, Codex, OpenClaw, Cursor, or Hermes Agent

## Installation

Install or set up from the source-backed instructions:

Install from the official website or GitHub Releases. For source or CLI setup, clone https://github.com/MemTensor/memmy-agent, follow the README installation path for your platform, then run memmy-memory init to add supported agent integrations and memmy-memory health/search/add/get for service checks and memory operations.
