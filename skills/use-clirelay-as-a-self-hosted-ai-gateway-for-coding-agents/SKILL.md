# Use CliRelay as a self-hosted AI gateway for coding agents

Route Claude Code, Codex, Gemini CLI, and OpenAI-compatible coding tools through a self-hosted gateway with tenant controls, request logs, quotas, and provider failover.

## Prerequisites

Go 1.26+, PostgreSQL 15+, CliRelay service, coding CLI clients such as Claude Code, Codex CLI, Gemini CLI, or OpenAI-compatible clients

## Installation

Install or set up from the source-backed instructions:

Follow the CliRelay repository and documentation to deploy the Go service with PostgreSQL, configure upstream provider credentials or account imports, create tenant or endpoint keys, and point supported coding CLIs at the generated OpenAI-compatible gateway endpoint.
