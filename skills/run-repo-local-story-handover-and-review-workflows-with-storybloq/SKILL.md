# Run repo-local story, handover, and review workflows with Storybloq

Use Storybloq when Claude Code or Codex needs durable repo-local stories, plans, handovers, lessons, and review evidence instead of rediscovering project state each session.

## Prerequisites

Node.js 20+, npm, Git, a local repository, Storybloq CLI/MCP server/skill, and a supported coding agent such as Claude Code or Codex CLI 0.130.0+; optional Storybloq Mac app.

## Installation

Install or set up from the source-backed instructions:

Install with `npm install -g @storybloq/storybloq@latest`, run `storybloq setup --client all` to install the Claude Code/Codex skill and MCP server, then initialize a project with `storybloq init --name `. In Claude Code invoke `/story`; in Codex invoke `$story` to load or update the repo-local project state.
