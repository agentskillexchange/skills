# Build and resume checked repository task graphs with Memdoor

Turn a repository procedure into Memdoor YAML tasks with explicit dependencies, completion checks, human approval gates and resumable run evidence.

## Prerequisites

Memdoor CLI and local gateway; shell and project test tools; supported provider API key or local model runtime

## Installation

Install or set up from the source-backed instructions:

Download the binary for your OS and architecture from https://github.com/guregodevo/memdoor/releases/tag/v1.808.0, verify it against that release's SHA256SUMS, and place memdoor on PATH. See the upstream GETTING_STARTED.md for platform setup. Configure a supported provider API key, such as OPENROUTER_API_KEY, in the environment, or connect a local model with memdoor connect local. Start memdoor from the target project; the gateway seeds its workflow skill. No npm package is required.
