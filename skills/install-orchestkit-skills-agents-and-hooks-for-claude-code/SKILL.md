# Install OrchestKit skills, agents, and hooks for Claude Code

Install OrchestKit when a Claude Code operator wants a maintained workflow pack of skills, specialist agents, hooks, setup automation, verification, PR review, commits, and persistent project memory.

## Prerequisites

Claude Code 2.1.251+ for full plugin support; optional Cursor, Codex, pi, Devin, or Antigravity support paths; recommended MCP servers such as Context7

## Installation

Install or set up from the source-backed instructions:

In Claude Code, run /plugin marketplace add yonatangross/orchestkit, then /plugin install ork, then /ork:setup. For skill-only hosts, use the upstream npx skills add yonatangross/orchestkit instructions.
