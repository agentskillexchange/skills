# Enforce engineering workflows with Ring skill packs

Use Ring to load curated engineering skills and specialist agents for TDD, systematic debugging, code review, product planning, and technical writing across supported agent hosts.

## Prerequisites

Supported agent host such as Claude Code, Codex, OpenCode, Cursor, or Factory AI; Git; optional Go tooling for Mithril-backed code analysis workflows

## Installation

Install or set up from the source-backed instructions:

Install through the Claude Code plugin marketplace for Claude Code, use the repository's native plugin manifests for Codex, OpenCode, or Cursor, or clone the repository and run bash ring-install.sh with the desired host flag such as --claude, --codex, or --opencode.
