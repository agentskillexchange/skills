# Carry project memory across coding agents with OpenWolf

Use OpenWolf to keep local project memory, handoff packets, project maps, and token usage records available across Claude Code, Codex, and OpenCode sessions.

## Prerequisites

OpenWolf CLI; target Git repository; Claude Code, Codex, or OpenCode workflow; optional OpenWolf dashboard

## Installation

Install or set up from the source-backed instructions:

Install the openwolf npm package or follow https://openwolf.com/getting-started. Run OpenWolf from the target repository, then use openwolf find, openwolf map, checkpoint, and handoff commands according to the upstream command docs.
