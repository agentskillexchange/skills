# Run autonomous coding tasks through Zeroshot verifier loops

Use Zeroshot when a coding issue or spec needs an executor agent and an independent verifier loop before the change is accepted.

## Prerequisites

Node.js >=18; one supported provider CLI such as Claude Code, OpenAI Codex, Gemini CLI, or OpenCode; Git repository access

## Installation

Install or set up from the source-backed instructions:

Install with npm install -g @the-open-engine/zeroshot, configure at least one supported provider CLI, then run zeroshot run .
