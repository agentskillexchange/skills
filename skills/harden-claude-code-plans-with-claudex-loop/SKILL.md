# Harden Claude Code plans with claudex-loop

Use claudex-loop when a Claude Code operator should lock intent, stress-test a plan with Codex, and cross-inspect the final build before approving risky work.

## Prerequisites

Claude Code with skills or plugin marketplace support, OpenAI Codex CLI 0.130 or newer, authenticated Codex CLI, local repository for brownfield work, optional web or deep research capability for greenfield planning

## Installation

Install or set up from the source-backed instructions:

Install as a Claude Code plugin with /plugin marketplace add chaseai-yt/claudex-loop and /plugin install claudex-loop@claudex-loop. Alternatively, copy the repository skills directory into ~/.claude/skills/ for bare skill names. Verify Codex CLI is installed and authenticated before invoking /claudex-loop, /codex-review, or /codex-build.
