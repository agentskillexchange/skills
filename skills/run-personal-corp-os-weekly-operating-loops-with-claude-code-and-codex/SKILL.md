# Run Personal Corp OS weekly operating loops with Claude Code and Codex

Install a maintained skill pack for weekly planning, retrospectives, task routing, department setup, and founder-ops workflows across Claude Code and Codex.

## Prerequisites

Claude Code or Codex with plugin/skill support, Git, local HQ and department folders; optional GitHub CLI for issue and project workflows

## Installation

Install or set up from the source-backed instructions:

Claude Code: claude plugin marketplace add serejaris/personal-corp-os, then claude plugin install personal-corp-os@personal-corp-os. Codex: codex plugin marketplace add serejaris/personal-corp-os, then codex plugin add personal-corp-os@personal-corp-os.
