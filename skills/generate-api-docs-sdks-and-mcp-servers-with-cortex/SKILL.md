# Generate API docs, SDKs, and MCP servers with Cortex

Use Cortex when an agent or API operator needs to turn OpenAPI, AsyncAPI, GraphQL, gRPC, OpenRPC, or Markdown sources into validated docs, typed SDKs, and a generated MCP server from one project config.

## Prerequisites

Node.js 20+, npm 10+, Cortex CLI, API specifications or Markdown sources

## Installation

Install or set up from the source-backed instructions:

Install with npm install --global @cortex-docs/cli, then run cortex init, cortex validate, and cortex generate to produce docs, SDKs, and the MCP server.
