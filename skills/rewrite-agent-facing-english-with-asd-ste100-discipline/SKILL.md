# Rewrite agent-facing English with ASD-STE100 discipline

Use this Claude Code skill to rewrite ambiguous instructions, errors, and tool descriptions into controlled technical English for agents.

## Prerequisites

Claude Code and either the skills CLI or a local ~/.claude/skills checkout

## Installation

Install or set up from the source-backed instructions:

From a project root, run npx skills add danyuchn/asd-ste100-skill. For a global Claude Code checkout, clone https://github.com/danyuchn/asd-ste100-skill into ~/.claude/skills/asd-ste100, then ask Claude Code to apply STE100, disambiguate text, or rewrite an instruction so an agent cannot misparse it.
