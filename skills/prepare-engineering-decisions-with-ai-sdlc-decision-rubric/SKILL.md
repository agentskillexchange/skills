# Prepare engineering decisions with AI-SDLC decision-rubric

Frame one consequential engineering choice with sourced evidence, distinct options, a counterargument, dependency checks and an operator decision.

## Prerequisites

Claude Code with AskUserQuestion; repository file and primary-source reading tools. Full AI-SDLC CLI only for optional Decision Catalog integration.

## Installation

Install or set up from the source-backed instructions:

Download https://raw.githubusercontent.com/ai-sdlc-framework/ai-sdlc/427da429c824dc4c54bf8153d806fd1409ce9439/ai-sdlc-plugin/skills/decision-rubric/SKILL.md to .claude/skills/decision-rubric/SKILL.md in the target project, then start a new Claude Code session and ask it to apply decision-rubric to one open engineering decision. Review the pinned instructions before adding them. The standalone rubric does not install the full AI-SDLC plugin or its Decision Catalog; catalog write-back requires the upstream framework setup.
