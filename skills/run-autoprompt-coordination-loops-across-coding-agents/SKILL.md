# Run Autoprompt coordination loops across coding agents

Use Autoprompt when an operator wants a coding agent to turn one goal into a planned, delegated, reviewed, and verified execution loop across supported agent runtimes.

## Prerequisites

Node.js 20+, Python 3.11+ with PyYAML exposed as python, Bash 4.3+ on macOS or Linux, Git for source checkout installs, and one supported coding-agent runtime such as Claude Code, Codex, OpenCode, Kilo Code, VS Code Copilot, or Prime Agent

## Installation

Install or set up from the source-backed instructions:

Install with npm install -g autoprompt-skill, run autoprompt, choose the target coding agent, confirm its path, and install. After installation, invoke /autoprompt in supported slash-command hosts or $autoprompt in Codex, optionally adding controls such as mode=wide or agents= where the host supports them.
