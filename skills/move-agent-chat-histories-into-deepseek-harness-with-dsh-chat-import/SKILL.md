# Move agent chat histories into DeepSeek Harness with DSH Chat Import

Preview, import, resume, export, and sync coding-agent conversations across Claude Code, Codex, ChatGPT, Cursor, Gemini, OpenClaw, and other tools as DeepSeek Harness sessions.

## Prerequisites

DeepSeek Harness, Node.js, npm, DSH Chat Import plugin

## Installation

Install or set up from the source-backed instructions:

Install the plugin in DeepSeek Harness with `dsh plugin --profile web add dsh-chat-import`, then use the Import sessions panel, `scan_discover()`, or import tools such as `import_chat`, `import_claude`, and `import_codex` to preview and import sessions.
