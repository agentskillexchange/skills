# Supervise tmux-based coding-agent sessions with agent-manager

Use agent-manager to launch, monitor, prompt, revive, and review multiple Claude Code, Codex, OpenCode, Grok, or Gemini CLI sessions running in persistent tmux sessions.

## Prerequisites

agent-manager CLI, tmux, supported terminal coding-agent CLIs, optional git worktrees

## Installation

Install or set up from the source-backed instructions:

Install with brew install yoanwai/tap/agent-manager on macOS/Linux, or download a release from https://github.com/YoanWai/agent-manager/releases. Ensure tmux and the target coding-agent CLIs are installed, then run agent-manager.
