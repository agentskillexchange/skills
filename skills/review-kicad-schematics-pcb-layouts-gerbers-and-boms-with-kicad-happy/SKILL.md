# Review KiCad schematics, PCB layouts, Gerbers, and BOMs with kicad-happy

Turn a coding agent into a KiCad electronics review assistant that parses boards, checks circuits, audits EMC risks, and prepares prototype-to-production feedback.

## Prerequisites

Python 3.10+, KiCad project files, Claude Code, Codex, GitHub Copilot CLI, Google Antigravity, opencode, or GitHub Actions

## Installation

Install or set up from the source-backed instructions:

Install through the documented agent path: in Claude Code add the marketplace with `/plugin marketplace add aklofas/kicad-happy` and `/plugin install kicad-happy@kicad-happy`; in Codex use `$skill-installer` for https://github.com/aklofas/kicad-happy or clone the repo and symlink the listed skills into `~/.codex/skills`.
