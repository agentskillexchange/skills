# Explain agent work in plain language with Open Steps

Run Open Steps so coding agents summarize work, generate plain-language verdicts, and hand off next steps that non-engineers can act on.

## Prerequisites

A supported coding agent such as Claude Code, Codex, Cursor, Gemini CLI, or another runtime that can read agent skill instructions.

## Installation

Install or set up from the source-backed instructions:

Install Open Steps from https://github.com/kharmanskyi/open-steps using the upstream instructions for your agent runtime, then invoke the included reporting skills when you need a plain-language session verdict, summary, risk note, or next-step handoff.
