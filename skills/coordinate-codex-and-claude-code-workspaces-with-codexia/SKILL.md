# Coordinate Codex and Claude Code workspaces with Codexia

Use Codexia when an operator needs a desktop or headless command center for Codex CLI, Claude Code, and ACP agents with task scheduling, git worktrees, remote control, skills, and session state.

## Prerequisites

Codexia, Codex CLI, Claude Code CLI for Claude Agent workflows, optional ACP-compatible agent

## Installation

Install or set up from the source-backed instructions:

Install with brew install --cask codexia on macOS, scoop install codexia on Windows after adding the milisp bucket, or download a prebuilt release from GitHub Releases.
