# Run multi-harness coding-agent sessions with Claudexor

Use Claudexor as a local-first control plane for Codex, Claude Code, Cursor, OpenCode, Antigravity, and API-backed coding harnesses with quotas, races, review gates, and durable evidence.

## Prerequisites

Node.js 20.19+, pnpm, Git, one or more supported vendor CLIs or provider API keys

## Installation

Install or set up from the source-backed instructions:

Install with npm install -g claudexor, run claudexor doctor, then connect Codex, Claude Code, Cursor, OpenCode, Antigravity, or API credentials before starting repository-bound runs.
