# Refresh Theia model aliases and provider capabilities with update-default-models

Research provider model changes, update Theia's default aliases and inferred capabilities, and return a tested maintenance patch using its upstream skill.

## Prerequisites

Git, Node.js >=24, npm, a coding agent, official provider documentation; gh optional

## Installation

Install or set up from the source-backed instructions:

Open an existing Theia source checkout or run git clone https://github.com/eclipse-theia/theia.git. Follow upstream contributor dependency setup with Node.js >=24. Have a compatible coding agent read .agents/skills/update-default-models/SKILL.md and explicitly request its model-refresh workflow. No separate MCP server is required.
