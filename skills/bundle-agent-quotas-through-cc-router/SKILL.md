# Bundle Agent Quotas Through cc-router

Run cc-router as a local desktop gateway that exposes Anthropic, OpenAI Responses, and Chat Completions endpoints so Claude Code, Codex, OpenClaw, OpenCode, and similar agent tools can use one managed pool of plans, quotas, and API providers.

## Prerequisites

cc-router desktop app, local machine access, provider/API credentials or supported plan credentials, compatible clients such as Claude Code, Codex CLI, OpenClaw, OpenCode, or Claude Desktop

## Installation

Install or set up from the source-backed instructions:

Download the platform installer from the latest GitHub release or the documented cc-router download page, then add providers and copy the generated local gateway configuration into the supported agent client.
