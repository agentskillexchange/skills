# Move an existing coding mission between machines with Orb checkpoints

Prepare a verified workspace checkpoint, move one Orb mission to an eligible machine on the same Core, and continue with its identity and history intact.

## Prerequisites

Orb client; configured Core backend; compatible registered machines; destination harness and authentication

## Installation

Install or set up from the source-backed instructions:

Follow upstream Core Docker/native setup and Orb client documentation. Configure DASHBOARD_PASSWORD and JWT_SECRET, review deployment mounts, and install compatible machine-transfer capabilities on Core, nodes and client. Open an existing mission, choose Change machine, prepare and review inventory, then confirm Move to the selected machine.
