# Run gated math modeling contest workflows with MathModeling Skills

Use MathModeling Skills when Claude Code or Codex should guide a math modeling contest project through staged parsing, method selection, code generation, review, frozen-number tracking, paper drafting, and submission packaging.

## Prerequisites

Claude Code or Codex/ChatGPT plugin support, git, Python/MATLAB or compatible contest tooling as needed by the selected modeling path

## Installation

Install or set up from the source-backed instructions:

Clone the repository, run `./install.sh`, and start a new Claude Code or Codex session. Use `./install.sh --target claude`, `./install.sh --target codex`, or `./install.sh --dry-run` for a narrower or previewed install.
