# Run long-horizon coding work with Late CLI

Use Late CLI to keep a lead coding agent focused while isolated researcher and coder subagents spend disposable compute on large implementation tasks.

## Prerequisites

Late CLI; target Git repository; supported cloud provider API key or local llama.cpp/llama-server; optional Podman/devcontainer runtime for isolated worker execution

## Installation

Install or set up from the source-backed instructions:

Install from the Homebrew tap with brew tap mlhher/late followed by brew install late on supported systems. From a project directory, run late; use late-podman only when isolated rootless container execution is desired and configured.
