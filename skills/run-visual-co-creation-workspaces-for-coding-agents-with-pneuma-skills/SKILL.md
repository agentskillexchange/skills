# Run visual co-creation workspaces for coding agents with Pneuma Skills

Use Pneuma Skills when Claude Code, Codex, or Kimi should build slides, documents, diagrams, videos, dashboards, or custom modes in real files while a human reviews and edits through a live visual workspace.

## Prerequisites

Pneuma Skills CLI or desktop app, Bun for CLI/source installs, one or more supported coding-agent backends such as Claude Code CLI, Codex CLI, or Kimi Code CLI, and a local workspace for generated artifacts.

## Installation

Install or set up from the source-backed instructions:

Use the documented desktop release for macOS, Windows, or Linux, or run the CLI with `bunx pneuma-skills`. For source installs, clone the repository, run `bun install`, and start a mode with commands such as `bunx pneuma-skills slide --workspace ./my-first-pneuma-slide` or `bunx pneuma-skills doc --backend claude-code`.
