# Route agent decisions through Hermes JEV Skills

Use Hermes JEV Skills when an operator wants fast, low-cost typed decisions for model routing, skill selection, memory filtering, search screening, mailbox triage, and browser or computer-use next actions.

## Prerequisites

Hermes JEV Skills, Python 3.9 or newer, TypeSafe/Jev API key for live Jev decisions, Hermes/Claude Code/Codex installation as applicable

## Installation

Install or set up from the source-backed instructions:

Clone https://github.com/kerpopule/hermes-jev-skills and run python3 install.py, then run jev setup-key and jev doctor. Use python3 install.py --check for a dry run before installing.
