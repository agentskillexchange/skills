# Inspect local coding-agent traces and share minimized reports with TraceCrate

Use TraceCrate to load Claude Code, Codex, OTLP, or native trace files locally, compare agent runs, inspect tool timelines, and export privacy-conscious structure-only reports.

## Prerequisites

TraceCrate, Node.js 22.12 or newer for local use, npm, and authorized local Claude Code, Codex, OTLP JSON, or TraceCrate native trace files.

## Installation

Install or set up from the source-backed instructions:

For local use, run git clone https://github.com/FankChen/tracecrate.git, cd tracecrate, npm install, and start the Vite app with the project command documented in the README. Open the printed local address, then choose or drop supported trace files you are authorized to inspect.
