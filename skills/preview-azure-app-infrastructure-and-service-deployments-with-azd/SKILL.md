# Preview Azure app infrastructure and service deployments with azd

Use Azure Developer CLI to inspect an existing azure.yaml project, preview infrastructure and service changes, and prepare an evidence-backed deployment handoff.

## Prerequisites

Azure Developer CLI (azd), existing azure.yaml project, reviewed infrastructure and hooks, configured Azure identity and environment

## Installation

Install or set up from the source-backed instructions:

Install azd from the official Azure/azure-dev release artifacts or the documented OS package manager; for Windows the upstream command is winget install microsoft.azd. Confirm azd version. Use an existing configured identity and project environment; review azure.yaml and local command help before running previews.
