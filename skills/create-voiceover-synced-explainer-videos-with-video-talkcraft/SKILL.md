# Create voiceover-synced explainer videos with video-talkcraft

Use video-talkcraft when a coding agent needs to turn a script and finished voiceover into a Remotion-rendered explainer video with timed motion, subtitles, QA, and reviewable shot structure.

## Prerequisites

Claude Code, Codex, or compatible coding agent; Node.js 18+; Python 3.10+; ffmpeg; Remotion dependencies installed by the skill workflow

## Installation

Install or set up from the source-backed instructions:

Install with npx skills add Vincentwei1021/video-talkcraft, or clone https://github.com/Vincentwei1021/video-talkcraft and link it into the target agent skills directory. Provide a script and voiceover file, then invoke the skill to generate the shotbook, timing, Remotion implementation, render, and QA outputs.
