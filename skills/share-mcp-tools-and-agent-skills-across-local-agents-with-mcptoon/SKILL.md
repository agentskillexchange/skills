# Share MCP tools and agent skills across local agents with mcptoon

Use mcptoon to install, index, inspect, and call MCP tools and agent skills from one local CLI while keeping bulky schemas and skill text out of every agent context.

## Prerequisites

Python 3, pip, local MCP servers or agent skills to index, and one or more supported local agents

## Installation

Install or set up from the source-backed instructions:

pip install mcptoon && mcptoon quickstart
