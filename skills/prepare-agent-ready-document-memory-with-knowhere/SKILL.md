# Prepare agent-ready document memory with Knowhere

Use Knowhere to parse complex documents into hierarchy-native, citation-backed memory that agents can retrieve and navigate.

## Prerequisites

Knowhere Cloud API or self-hosted Knowhere stack, document corpus, configured model or vision model provider for parsing where needed, and an agent/RAG client that consumes the generated memory or MCP-compatible retrieval interface

## Installation

Install or set up from the source-backed instructions:

Use Knowhere Cloud from https://knowhereto.ai for the managed API, or self-host the Knowhere stack with the upstream Docker Compose instructions linked from the repository. Configure the required model provider, ingest documents, run parsing jobs, then connect agents or RAG clients to the generated hierarchy-native retrieval memory.
