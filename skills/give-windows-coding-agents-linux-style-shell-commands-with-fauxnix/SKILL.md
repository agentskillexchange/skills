# Give Windows coding agents Linux-style shell commands with Fauxnix

Install Fauxnix so agents on Windows can issue familiar Linux-style shell commands that are translated deterministically to native PowerShell.

## Prerequisites

Windows, PowerShell 5.1+, Node.js 18+, npm, MCP-compatible agent client

## Installation

Install or set up from the source-backed instructions:

Install with `npm install -g fauxnix-cli`, run `fauxnix install --claude`, `--codex`, `--opencode`, `--kimi`, or `--qwen` for the target client, then run `fauxnix doctor` to verify encoding, config, and MCP round-trip.
