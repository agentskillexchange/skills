# Run terminal coding-agent workflows with Phi

Use Phi to run lightweight terminal coding-agent sessions with sub-agents, guarded tool use, hashline edits, and lazy MCP discovery.

## Prerequisites

Phi CLI/TUI, a configured OpenAI-compatible or Anthropic model API key, local git repository, optional MCP servers, optional Phi skills and hooks

## Installation

Install or set up from the source-backed instructions:

Install from the published GitHub release or build from source with Go 1.26.3+ using git clone https://github.com/pulseaiclub/phi.git, cd phi, and make install. Then run phi config or set PHI_MODEL and PHI_API_KEY, start the TUI with phi, or run a bounded headless task with phi run -p "".
