# Build spec-driven full-stack apps with Wasp

Use Wasp when an agent needs to scaffold or modify a React, Node.js, and Prisma app from a compact declarative spec with auth, RPC, jobs, email, and deployment conventions.

## Prerequisites

Wasp CLI, Node.js, npm, React, Node.js server runtime, Prisma

## Installation

Install or set up from the source-backed instructions:

Install the official CLI with npm i -g @wasp.sh/wasp-cli@latest, then follow the Wasp quick start and agent integration docs to create or modify the app through main.wasp.ts and related React, Node.js, and Prisma files.
