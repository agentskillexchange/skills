# Validate a YouTube niche with sourced channel evidence through TubeLab

Compare up to three YouTube niches using channel samples, explicit score formulas and newcomer evidence to produce an entry verdict.

## Prerequisites

An agent with skill support and an authenticated TubeLab MCP connection; TubeLab plan and search credits

## Installation

Install or set up from the source-backed instructions:

npx skills add TubeLabHQ/youtube-research-skills --skill niche-validator --skill tubelab-mcp Connect https://public-api.tubelab.net/mcp in the agent client using the upstream setup guide and complete its supported authentication. Invoke niche-validator with a niche or shortlist of up to three. Search calls require available credits.
