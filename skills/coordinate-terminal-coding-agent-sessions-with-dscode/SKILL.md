# Coordinate terminal coding-agent sessions with DSCODE

Use DSCODE when an operator needs a macOS terminal coding agent with a persistent shell, session bridge, agent-to-agent task handoffs, independent review, and Chrome MCP or telemetry-backed automation.

## Prerequisites

DSCODE, macOS 14 or newer, Node.js 22.19 or newer or Node.js 24, DeepSeek Harness runtime

## Installation

Install or set up from the source-backed instructions:

Run npm install -g @toddzheng024/dscode, open a project with cd /path/to/project, start dscode, then use commands such as dscode sessions, dscode send, dscode read, /delegate, /review, and /permission auto-review for session orchestration.
