# Run RFC-driven product planning with AI PRD Workflow before agents code

Guide coding agents from idea or existing codebase through PRD, features, rules, RFCs, implementation, review, and workflow-status checks.

## Prerequisites

Claude Code plugin or supported agent skills directory for Codex, GitHub Copilot, Cursor, Gemini CLI, OpenCode, or Devin; existing project directory; shell access for install script

## Installation

Install or set up from the source-backed instructions:

For Claude Code, add the marketplace repository and install prd-workflow@ai-prd-workflow. For Codex, Copilot, Cursor, Gemini CLI, OpenCode, or Devin, run the upstream install.sh script against the target project, restart the agent runtime, then run the documented commands in order.
