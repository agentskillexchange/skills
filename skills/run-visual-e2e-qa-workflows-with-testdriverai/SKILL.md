# Run visual E2E QA workflows with TestDriverAI

Use TestDriverAI to initialize, author, and run vision-assisted Vitest E2E checks for browser, desktop, extension, chatbot, OAuth, upload, iframe, canvas, and other hard-to-test flows.

## Prerequisites

TestDriverAI account and API key, Node.js/npm, Vitest, TestDriverAI SDK, and optional MCP-capable assistant integration.

## Installation

Install or set up from the source-backed instructions:

Run npx testdriverai init in the target project, follow the prompts to install Vitest and TestDriverAI, configure the API key and assistant integration, then execute the generated or edited tests with vitest run.
