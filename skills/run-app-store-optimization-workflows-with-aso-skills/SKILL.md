# Run App Store Optimization Workflows With ASO Skills

Use ASO Skills to run repeatable App Store keyword research, metadata optimization, competitor analysis, and growth planning from an agent session.

## Prerequisites

Agent Skills-compatible host such as Cursor, Claude Code, or another compatible AI assistant; npx skills CLI for Claude Code installation; optional Appeeky API access for live App Store data workflows

## Installation

Install or set up from the source-backed instructions:

For Cursor, add a remote rule pointing to `https://github.com/eronred/aso-skills`. For Claude Code, run `npx skills add eronred/aso-skills`. For manual setup, clone the repo and copy `aso-skills/skills/*` into `.cursor/skills/`, then invoke `/aso-skill` or a specific skill such as `/aso-audit`, `/keyword-research`, `/metadata-optimization`, `/market-movers`, `/android-aso`, `/apple-search-ads`, or `/competitor-tracking`.
