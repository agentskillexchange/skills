# Review agent-authored diffs in terminal with herdr-reviewr

Open a terminal review pane beside a coding agent, inspect changed files, add line comments, and send structured review notes back to the agent without leaving the terminal.

## Prerequisites

herdr 0.7.5 or newer, git, macOS or Linux terminal, and optional authenticated gh, glab, or az CLI for PR view

## Installation

Install or set up from the source-backed instructions:

herdr plugin install persiyanov/herdr-reviewr
