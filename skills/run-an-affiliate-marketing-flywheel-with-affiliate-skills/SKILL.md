# Run an affiliate marketing flywheel with affiliate-skills

Use affiliate-skills to chain agent workflows for program research, trend scouting, content creation, landing pages, compliance, analytics, and optimization.

## Prerequisites

Agent Skills-compatible AI client; optional Claude Code, Pi, ChatGPT, Gemini CLI, Cursor, Windsurf, or OpenClaw; Node/npm for npx skills add; optional ClawHub/OpenClaw; chosen external research, analytics, and publishing accounts

## Installation

Install or set up from the source-backed instructions:

Install with npx skills add Affitor/affiliate-skills for supported Agent Skills clients, clone manually into a skills directory and run ./setup if needed, or run clawhub install affiliate-skills in OpenClaw/ClawHub.
