# Monitor Claude Code sessions with ccstatusline

Configure Claude Code's status line with live model, token, cost, git, sandbox, cache, CI, and session health signals so operators can supervise coding-agent work from the terminal.

## Prerequisites

Claude Code CLI, Node.js, npm or Bun

## Installation

Install or set up from the source-backed instructions:

Install with npm install -g ccstatusline or the documented Bun path, then run the ccstatusline setup/configuration flow and enable it as Claude Code's statusLine command. Use the TUI to choose widgets for model, usage, cost, git, CI, cache, sandbox, and health signals.
