# Control Codex and Claude coding-agent sessions from mobile with CC Pocket

Run a self-hosted bridge so an operator can start, resume, approve, and review Codex or Claude Code sessions from a phone or tablet.

## Prerequisites

Node.js 20.18.1+, @ccpocket/bridge, Codex CLI and/or Claude Code CLI, CC Pocket mobile or desktop app

## Installation

Install or set up from the source-backed instructions:

Install Codex or Claude Code on the host machine, run `npx @ccpocket/bridge@latest`, install CC Pocket on the mobile or desktop client, then scan the Bridge Server QR code to connect. For persistent hosts, run `npx @ccpocket/bridge@latest setup` after setting any required bridge environment variables.
