# Generate budgeted McDonald’s China group-meal plans

Compare nearby McDonald’s China stores and live-priced meal combinations against a group headcount and budget, returning a plan without ordering.

## Prerequisites

Python 3.9+; authorized McDonald’s China MCP token; repository checkout; network access

## Installation

Install or set up from the source-backed instructions:

Clone the source repository and check out the documented source commit. Obtain your own token from https://open.mcd.cn/mcp and configure MCD_MCP_TOKEN in the repository .env. No pip dependencies. Run python -m src.cli selfcheck before live planning. WorkBuddy is optional for the CLI route. Source commit: 40b91ffa00e189b4d8ed8011aa97ff52c0d8a124.
