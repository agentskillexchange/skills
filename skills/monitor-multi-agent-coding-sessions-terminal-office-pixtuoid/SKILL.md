# Monitor multi-agent coding sessions in a terminal office with Pixtuoid

Use Pixtuoid as a terminal dashboard that shows multiple coding agents as live session avatars so operators can spot waiting, active, and finished work.

## Prerequisites

Pixtuoid CLI, terminal environment, supported coding-agent CLI such as Claude Code or Codex

## Installation

Install or set up from the source-backed instructions:

Install with `brew install pixtuoid` or `npm install -g pixtuoid`, run `pixtuoid`, open the Sources panel with `s`, connect the desired agent CLI, then start that agent in another terminal and use `pixtuoid doctor` if integration health needs checking.
