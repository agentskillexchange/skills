# Run senior engineering workflows in Claude Code with Senior Engineering Partner

Use Senior Engineering Partner to run Claude Code through review, pair-programming, debugging, mentoring, and audit workflows with spec, test, security, and verification discipline.

## Prerequisites

Claude Code, the Senior Engineering Partner skill or plugin, git for clone-based installation, and optional project-specific tooling referenced by the skill's on-demand engineering references.

## Installation

Install or set up from the source-backed instructions:

Install as a Claude Code plugin with /plugin marketplace add bjgreenberg/senior-engineering-partner and /plugin install senior-engineering-partner@bjgreenberg, or clone it with git clone https://github.com/bjgreenberg/senior-engineering-partner ~/.claude/skills/senior-engineering-partner. Invoke it with /senior-engineering-partner, optionally using mode triggers such as REVIEW:, DEBUG:, or AUDIT:.
