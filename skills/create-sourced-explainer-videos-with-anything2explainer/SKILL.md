# Create sourced explainer videos with anything2explainer

Use anything2explainer as an agent workflow for turning a topic or document into a sourced Remotion explainer video with narration, subtitles, checkpoints, and QC.

## Prerequisites

Claude Code or Codex-style SKILL.md agent, Remotion, Node.js 18+, ffmpeg, Python 3, edge-tts or kokoro/compatible TTS

## Installation

Install or set up from the source-backed instructions:

git clone https://github.com/Vincentwei1021/anything2explainer.git && ln -s "$PWD/anything2explainer" ~/.claude/skills/anything2explainer or ln -s "$PWD/anything2explainer" ~/.codex/skills/anything2explainer; then install ffmpeg, Python TTS dependencies, and run the included Remotion template workflow.
