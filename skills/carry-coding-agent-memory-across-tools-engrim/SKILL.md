# Carry Coding-Agent Memory Across Tools with Engrim

Use Engrim to give Codex CLI, Claude Code, Cursor, OpenCode, GitHub Copilot CLI, and Google Antigravity a shared local SQLite memory for project decisions, resumable context, and cross-agent continuity.

## Prerequisites

Python 3.10 or newer, engrim package, supported coding-agent environments such as Codex CLI, Claude Code, Cursor, OpenCode, GitHub Copilot CLI, or Google Antigravity

## Installation

Install or set up from the source-backed instructions:

Install with pip install engrim, then run engrim setup to auto-detect supported environments. Use engrim doctor --fix to repair hook or MCP integration issues.
