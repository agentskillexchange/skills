# Run local coding agents from Feishu or Lark with Lark Coding Agent Bridge

Use Lark Coding Agent Bridge to connect Feishu or Lark chat threads to a local Claude Code or Codex CLI session with streaming cards, per-chat continuity, workspace switching, file handling, and controlled slash commands.

## Prerequisites

lark-channel-bridge, Node.js 20.12.0+, Feishu or Lark PersonalAgent app, Claude Code or Codex CLI

## Installation

Install or set up from the source-backed instructions:

Install with npm i -g lark-channel-bridge or pnpm add -g lark-channel-bridge. Run lark-channel-bridge run, scan the QR code, bind or create a Feishu/Lark PersonalAgent app, then choose Claude Code or Codex as the local agent profile.
