# Design and Audit Agent Harnesses with Agents Best Practices

Use Agents Best Practices when an agent should produce concrete harness designs, permission models, memory plans, eval gates, or production-readiness audits.

## Prerequisites

A compatible agent skill runtime such as Codex skills, Claude Code skills, or the skills CLI; local access to the installed SKILL.md and references directory.

## Installation

Install or set up from the source-backed instructions:

Install as a portable Agent Skill. With the skills CLI, run npx skills add DenisSergeevitch/agents-best-practices -g. For Codex, clone the repo into CODEX_HOME/skills/agents-best-practices or $HOME/.codex/skills/agents-best-practices. For Claude Code, clone it into $HOME/.claude/skills/agents-best-practices or a project .claude/skills/agents-best-practices directory.
