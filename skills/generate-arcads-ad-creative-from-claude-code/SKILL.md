# Generate Arcads ad creative from Claude Code

Use the Arcads Claude Code skill pack to create, poll, organize, and review AI marketing videos and image ads through the Arcads API.

## Prerequisites

Arcads account and API key; Python 3.10+; Claude Code or Cursor; optional ffmpeg, jq, Node.js/npx hyperframes, openai-whisper, and Meta Marketing API dependencies for advanced workflows

## Installation

Install or set up from the source-backed instructions:

Clone https://github.com/krusemediallc/arcads-claude-code, cd into the repository, run ./scripts/setup.sh, provide an Arcads API key, then open the folder in Claude Code or Cursor.
