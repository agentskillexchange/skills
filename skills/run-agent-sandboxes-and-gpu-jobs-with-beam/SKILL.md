# Run agent sandboxes and GPU jobs with Beam

Use Beam when an agent needs remote Python sandboxes, serverless GPU inference endpoints, or retryable background tasks without managing infrastructure.

## Prerequisites

Beam client, Python, Beam account or self-hosted Beam runtime, container/GPU resources as needed

## Installation

Install or set up from the source-backed instructions:

Install the Python client with pip install beam-client, complete the Beam onboarding or self-hosted setup, then define Sandbox, endpoint, or task_queue workloads in Python and deploy or invoke them with the Beam tooling.
