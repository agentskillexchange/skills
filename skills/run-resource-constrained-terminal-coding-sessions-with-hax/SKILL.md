# Run resource-constrained terminal coding sessions with hax

Use hax as a lightweight terminal-native coding agent for local-model, provider-backed, or Unix-composed code workflows where low overhead and inspectable transcripts matter.

## Prerequisites

hax binary, terminal shell, project directory, configured provider or local model runtime such as llama.cpp or Ollama

## Installation

Install or set up from the source-backed instructions:

Install with Homebrew using `brew install oleksandrchekhovskyi/hax/hax`, install the Arch AUR package `hax`, download a prebuilt static binary from https://github.com/OleksandrChekhovskyi/hax/releases/latest, or build from source with `git clone https://github.com/OleksandrChekhovskyi/hax.git`, `cd hax`, install the documented dependencies, `make`, and optionally `make install`.
