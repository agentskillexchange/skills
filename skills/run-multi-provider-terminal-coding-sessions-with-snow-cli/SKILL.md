# Run multi-provider terminal coding sessions with Snow CLI

Use Snow CLI as a terminal coding agent that can route repository work through OpenAI, Gemini, Claude, DeepSeek, or compatible providers without switching tools.

## Prerequisites

Node.js or npm-compatible runtime, Git repository, API credentials or relay route for the selected model provider

## Installation

Install or set up from the source-backed instructions:

Install the snow-ai package from npm, then run the Snow CLI from a target repository and configure the desired provider credentials or relay endpoint.
