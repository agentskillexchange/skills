# Run repeatable marketing operator workflows with Aaron Marketing Skills

Install a maintained marketing skill library so agents can run scoped SEO/GEO, email, paid ads, influencer, launch, social, and brand narrative workflows with shared quality gates.

## Prerequisites

Claude Code or another Agent Skills-compatible host, Git or npx skills, optional shell access for local clone workflows

## Installation

Install or set up from the source-backed instructions:

For Claude Code, run `/plugin marketplace add aaron-he-zhu/aaron-marketing-skills` and then `/plugin install aaron-marketing@aaron`. For other supported hosts, run `npx skills add aaron-he-zhu/aaron-marketing-skills` or clone the repository, then invoke `/aaron-marketing:auto` or a discipline command.
