# Manage agent runtime capabilities with CAPA

Use CAPA to declare coding-agent skills, rules, tools, MCP servers, sub-agents, and plugins once in capabilities.yaml, then install native provider files across Cursor, Claude Code, Codex, Windsurf, Copilot, Gemini CLI, and related agents.

## Prerequisites

CAPA CLI, capabilities.yaml, supported AI coding-agent runtimes, optional MCP servers/tools declared by the project

## Installation

Install or set up from the source-backed instructions:

Install from the upstream release or review and run the installer published at https://capa.infragate.ai. In a repo, run capa init, edit capabilities.yaml, then run capa install.
