# Map codebase context for agents with Ripwire

Use Ripwire to give coding agents deterministic repository maps, task-relevant symbols, blast radius, and test guidance before they edit.

## Prerequisites

Ripwire CLI, local repository checkout, shell access, optional MCP-capable coding agent, optional Codex plugin skills

## Installation

Install or set up from the source-backed instructions:

Install the Ripwire release binary or build from source, ensure ripwire is on PATH, optionally register the included MCP server with ripwire --mcp and install the bundled agent skills, then run ripwire . --for="your task" or ripwire . --pr-context from the target repository before editing or reviewing.
