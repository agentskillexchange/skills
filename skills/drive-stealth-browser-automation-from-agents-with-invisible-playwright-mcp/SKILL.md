# Drive stealth browser automation from agents with Invisible Playwright MCP

Use Invisible Playwright MCP when an agent needs a self-hosted browser automation runtime for permitted web research, scraping, form navigation, and computer-use workflows that must run through a real headed browser.

## Prerequisites

Invisible Playwright MCP, uv/uvx, MCP-capable assistant or supported plugin host such as Claude Code, Codex, or Gemini CLI

## Installation

Install or set up from the source-backed instructions:

Install uv, then add the upstream plugin to a supported agent, for example `codex plugin marketplace add feder-cr/invisible_playwright_mcp` and `codex plugin add invisible-playwright-mcp@feder-cr`. For standalone UI usage, run `uvx invisible-playwright-mcp ui --openrouter-key sk-or-...`.
