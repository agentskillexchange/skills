# Orchestrate coding-agent goals and context with Jumbo Context

Use Jumbo Context when coding agents need local goal state, project memory, session continuity, and context packets that travel across Claude, Codex, Copilot, and other harnesses.

## Prerequisites

Node.js and npm; jumbo-cli installed globally; coding agent with AGENTS.md support or hooks for best results; local filesystem access

## Installation

Install or set up from the source-backed instructions:

Install globally with npm i -g jumbo-cli, run jumbo in the project folder, define or refine a goal, then start the coding agent and ask it to follow the Jumbo-provided instructions.
