# Watch local agent token usage and session traces with TokenTelemetry

Use TokenTelemetry to read local Claude Code, Codex, Gemini CLI, Hermes, and other agent logs into a dashboard for token usage, costs, tool calls, project activity, budgets, and session traces.

## Prerequisites

TokenTelemetry, Python 3.9 or newer, supported local agent logs such as Claude Code, Codex, Gemini CLI, Cursor, OpenCode, Hermes Agent, or similar.
