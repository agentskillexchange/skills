# Coordinate a scoped code change through Oh My Claudecode team stages

Run a bounded Claude Code team task through planning, delegated implementation, verification and repair, then return the change and evidence for operator review.

## Prerequisites

Claude Code with provider access, upstream oh-my-claudecode plugin, repository checkout and project-specific checks; native teams enabled for the selected team runtime

## Installation

Install or set up from the source-backed instructions:

Inside Claude Code, enter /plugin marketplace add https://github.com/Yeachan-Heo/oh-my-claudecode and /plugin install oh-my-claudecode separately, then /omc-setup. Enable CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 in Claude Code settings. Invoke /oh-my-claudecode:team with a scoped task.
