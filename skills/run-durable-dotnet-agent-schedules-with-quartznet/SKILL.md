# Run durable .NET agent schedules with Quartz.NET

Use Quartz.NET to schedule recurring, delayed, or cron-triggered .NET agent jobs with persistent triggers, hosted-service integration, and reviewable job definitions.

## Prerequisites

.NET SDK/runtime and the Quartz NuGet package

## Installation

Install or set up from the source-backed instructions:

Install the package with `dotnet add package Quartz`, define Quartz jobs and triggers in the .NET service, and wire the scheduler into the hosted application using the upstream quick-start documentation.
