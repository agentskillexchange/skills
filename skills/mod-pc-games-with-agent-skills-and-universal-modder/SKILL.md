# Mod PC games with agent skills and Universal Modder

Use Universal Modder to let coding agents inspect a PC game, plan the mod route, generate assets, test in-game, and capture reusable field notes.

## Prerequisites

Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot, OpenCode, or another AGENTS.md-aware coding agent; local PC game files; optional fal access for generated art, 3D, and audio assets.

## Installation

Install or set up from the source-backed instructions:

Install through the upstream path for your agent: Claude Code plugin marketplace, Codex plugin marketplace, Gemini extension install, VS Code plugin-from-source, Cursor marketplace or clone, npx skills add for skills-only use, or a direct git clone. Follow the repository README to expose the skills, MCP config, and um CLI to the chosen agent.
