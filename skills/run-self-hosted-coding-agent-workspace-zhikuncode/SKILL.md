# Run a Self-Hosted Coding Agent Workspace with ZhikunCode

Use ZhikunCode to deploy a browser-based, self-hosted coding-agent workspace with CLI and web entry points, multi-agent collaboration, model provider configuration, persistent sessions, and sandbox controls.

## Prerequisites

Docker 20.10+, Docker Compose V2, LLM provider/API credentials, configured workspace volume or allowed project roots

## Installation

Install or set up from the source-backed instructions:

Use the upstream Docker deployment: git clone https://github.com/zhikunqingtao/zhikuncode.git && cd zhikuncode, copy .env.example to .env, add API keys and workspace settings, then run docker compose up -d and open http://localhost:8080.
