## Initial release

First standalone release candidate.

- Goal-based discovery for peers, collaborators, mentors, event contacts, and existing communities.
- Professional relevance, identity evidence, and relationship context kept distinct.
- Private SQLite ledger with normalised profile destinations, transactional batch reservations, exact-list preservation, and append-only observation events.
- Guidance for explicitly authorised invitations, uncertain-attempt recovery, and canonical tracker reconciliation.
- Generic JSON input, standard-library-only helper, fictional demo data, and an installer that refuses overwrites.
- Allowlisted ZIP packaging with file manifests and archive checksums.

The agent supplies research and browser capabilities. The helper does not operate
LinkedIn, authenticate accounts, or enforce the truth of recorded observations.
This candidate has no hosted service, campaign scheduler, or built-in CRM adapters.
