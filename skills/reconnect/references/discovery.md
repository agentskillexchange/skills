# Discovery and identity resolution

1. Establish the networking purpose, relevant topics/roles, relationship context,
   explicit exclusions, and permitted sources from the request and project records.
   A community or roster is optional. For new contacts, begin with public work,
   conference speakers, projects, or professional communities related to the goal.
2. Reuse stored candidates and search attempts before searching again. Prioritise
   unresolved active contributors if requested, without treating participation as
   identity evidence. Preserve a last-attempt date and reason for inconclusive work.
3. Search public sources with a name plus affiliation, year, course, project, or
   collaborator. Try name-order variants and declared aliases. Use personal sites,
   university pages, GitHub profiles and public Git history to find declared links.
   Query search engines for LinkedIn profiles instead of repeatedly searching an
   authenticated LinkedIn session. Independent public research can run in parallel;
   authenticated LinkedIn stays sequential.
4. Prefer direct cross-links over same-name matches. Record each source URL, retrieval
   date, supported claim, and contradiction. Check chronology and role. Keep multiple
   hypotheses when evidence cannot distinguish namesakes; do not select one by score.
5. Review identity and professional relevance independently. Someone can be correctly
   identified but have little connection to the user's goal. Shared employer, field,
   or event does not prove a personal relationship. Sparse online activity does not
   make someone irrelevant; assess the available work and context.
6. Admit candidates using the tracking format. Use `review` for unresolved identity
   or eligibility; use `eligible` only with recorded supporting evidence. Preserve
   existing exclusions and known relationship states when refreshing records.

Avoid copying private correspondence, email addresses, or sensitive records into skill
outputs. A private source ID and its evidence pointer normally suffice. Keep public
search scope professional and relevant; do not infer sensitive traits or hunt for
private contact details. If a public URL is dead, preserve the old record and seek a
new destination with evidence; do not blindly retry it.

When discovery is exhausted, report unmatched people and the specific evidence gap.
An exhausted queue is not authority to expand to unrelated people.
