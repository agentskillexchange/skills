# Maintain reusable project knowledge with Project Cairn

Use Project Cairn to initialize, maintain, audit, and graduate project knowledge so coding-agent work leaves reusable decisions and lessons behind.

## Prerequisites

Skill-compatible agent such as Claude Code, Codex, WorkBuddy, or another runtime that can load a SKILL.md directory; git; bash for scripts/*.sh; Python 3 for scripts/*.py; optional PyYAML for notion-graduate-batch.py; optional Obsidian, Notion, or Lark / Feishu knowledge base for graduation workflows

## Installation

Install or set up from the source-backed instructions:

Clone the repository into the skill directory for the target agent so SKILL.md sits at the root of project-cairn. For Claude Code, use git clone https://github.com/iBlinkQ/project-cairn.git ~/.claude/skills/project-cairn. For Codex, use git clone https://github.com/iBlinkQ/project-cairn.git ~/.agents/skills/project-cairn. In a project, ask the agent to initialize Project Cairn, then use the documented init, maintenance, audit, consume, graduation, upgrade, and branch-closure references as needed.
