# Apply atomic tracked Word revisions with SurfSense

Apply requested edits to one Word source as a versioned Studio copy, using exact-text anchors, atomic edit batches and tracked-change review.

## Prerequisites

SurfSense desktop Agentic chat; configured model connection; bundled surfsense-revisions skill; surfsense_read_document and surfsense_revise_document; one ready DOCX source; Studio review

## Installation

Install or set up from the source-backed instructions:

Install SurfSense v2.4.0 or a newer compatible desktop release from https://www.surfsense.com/downloads or the official MODSetter/SurfSense GitHub releases. Complete onboarding and configure the intended model. Add the DOCX to Sources and wait until ready, then open an Agentic chat and name the file plus requested edits. The surfsense-revisions skill is bundled; no separate npm package or external MCP registration is required.
