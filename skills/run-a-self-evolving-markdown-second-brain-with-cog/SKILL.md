# Run a self-evolving markdown second brain with COG

Use COG to onboard a markdown-based second brain with agent skills for braindumps, briefs, reviews, research, product work, and verifier-backed workflows.

## Prerequisites

Git, a markdown-reading or skill-aware agent runtime such as Claude Code, Cursor, Kiro, Gemini CLI, or Codex; optional Obsidian

## Installation

Install or set up from the source-backed instructions:

Clone https://github.com/huytieu/COG-second-brain, open the folder in the chosen agent runtime, and ask the agent to run onboarding. Claude Code uses .claude/skills, Kiro uses .kiro/powers, Gemini CLI uses .gemini commands and skills, and other agents can follow AGENTS.md.
