# Run social media research workflows with ScrapeCreators skills

Use Social Media Research Skills when an agent needs to find outlier posts, mine comments, compare competitors, inspect ad libraries, and turn public social data into cited marketing research artifacts.

## Prerequisites

Agent Skills-compatible runtime, Node.js/npx, ScrapeCreators API key in SCRAPECREATORS_API_KEY, WebFetch-capable agent tools

## Installation

Install or set up from the source-backed instructions:

Run npx skills add ScrapeCreators/social-media-research-skills, then set SCRAPECREATORS_API_KEY in the agent environment before invoking the installed social research skills.
