# Audit local agent runs and select hook policies with Failproof AI

Review local harness history, identify risky tool patterns, and prepare a source-backed policy-pack rollout across supported agent runtimes.

## Prerequisites

Node.js, npm, Failproof AI CLI, supported agent harness and authorized local run history

## Installation

Install or set up from the source-backed instructions:

Install the documented CLI with npm install -g failproofai. Review host changes before failproofai config; inspect the policy pack before adding it. Audit an existing installation with FAILPROOFAI_NO_FIRST_RUN=1.
