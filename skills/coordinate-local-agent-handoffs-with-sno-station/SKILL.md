# Coordinate local agent handoffs with Sno Station

Use Sno Station to give Claude Code, Codex, OpenClaw, and related local agents shared encrypted memory, handoff messaging, peer review, and approved skill improvement loops.

## Prerequisites

Local machine access, supported harnesses such as Claude Code, Codex, OpenClaw, or Hermes Agent, and the Sno CLI installed from the upstream installer.

## Installation

Install or set up from the source-backed instructions:

Run the upstream installer from https://sno.ai/install, then run `sno setup --harness codex`, `sno setup --harness claude`, `sno setup --harness openclaw`, or another supported harness. In an agent session, say `Sno onboarding` to complete the guided setup.
