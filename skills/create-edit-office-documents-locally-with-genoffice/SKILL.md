# Create and edit Office documents locally with GenOffice

Use GenOffice's CLI and bundled agent skill to create, inspect, convert, render, audit, and edit real DOCX, XLSX, PPTX, PDF, Markdown, and HTML files from an agent session.

## Prerequisites

GenOffice desktop app; genoffice CLI; bundled GenOffice agent skill; target DOCX/XLSX/PPTX/PDF/Markdown/HTML files or source brief/data; optional configured AI/search/image/media providers

## Installation

Install or set up from the source-backed instructions:

Install GenOffice from the latest GitHub release for macOS, Windows, or Linux. Install the skill from Settings -> Integrations, download the skill zip, or run `npx skills add genspark-ai/genoffice`; confirm CLI availability with `genoffice --version`.
