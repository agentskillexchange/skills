# Monitor local coding-agent sessions and token usage with Loongsuite Pilot

Collect local telemetry from Claude Code, Codex, Cursor, OpenClaw, OpenCode, and related coding agents, then inspect token usage, tool calls, sessions, and traces from one local dashboard or OpenTelemetry pipeline.

## Prerequisites

Node.js 18+, npm, curl or wget, supported local coding agents such as Claude Code, Codex, Cursor, OpenClaw, OpenCode, or related hook/plugin-compatible agents; PowerShell 5.1+ on Windows
