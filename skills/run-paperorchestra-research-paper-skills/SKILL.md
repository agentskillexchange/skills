# Run PaperOrchestra Research-Paper Skills

Use PaperOrchestra's host-agent skill pack to turn research ideas, logs, literature, figures, drafts, and autorater checks into a repeatable assisted LaTeX paper-writing pipeline.

## Prerequisites

PaperOrchestra skill pack, a host coding/research agent such as Claude Code, Cursor, Antigravity, Cline, Aider, OpenCode, or similar, local deterministic helper scripts, optional LaTeX and literature-search tools

## Installation

Install or set up from the source-backed instructions:

Clone the GitHub repository and point the host agent at the skills/paper-orchestra skill pack. Follow the repository's host integration notes and run the deterministic helper scripts from the provided skills and references directories as instructed.
