# Design, render, and visually QA editable PowerPoint decks with PPT Design Skill

Run a presentation-design workflow that turns a confirmed brief into editable PPTX output, rendered PNG previews, and revision loops before delivery.

## Prerequisites

Python 3, pptx-designer, PowerPoint or LibreOffice/Poppler for render QA, Claude Code/Codex/OpenCode/DeepSeek Harness skill runtime

## Installation

Install or set up from the source-backed instructions:

Clone the repository, run `python installer/install.py --platform codex --force` or the matching supported platform (`claude`, `opencode`, `deepseek-harness`, or `all`), then run `python skill/scripts/check_runtime.py`. Use `--render-deps` only when explicitly installing LibreOffice/Poppler render dependencies.
