# Produce cinematic product videos with Video Shotcraft

Turns Claude Code, Codex, or another skills-aware coding agent into a Remotion-based product video operator with shot cards, motion previews, templates, capture scripts, sound design, and visual QA.

## Prerequisites

Video Shotcraft skill, Claude Code or Codex, Node.js, Remotion, product screenshots or page captures, browser rendering environment for previews, and ffmpeg for final inspection when rendering video

## Installation

Install or set up from the source-backed instructions:

Ask the agent to install https://github.com/Vincentwei1021/video-shotcraft, run npx skills add Vincentwei1021/video-shotcraft, or clone the repository and symlink it into ~/.claude/skills/video-shotcraft or ~/.codex/skills/video-shotcraft.
