# Use Superpowers Symfony for Claude Code Symfony workflows

Install a Claude Code plugin that gives agents repeatable Symfony, Doctrine, API Platform, Messenger, security, TDD, and quality-check workflows.

## Prerequisites

Claude Code; Symfony project; optional Docker Compose, Symfony Docker/FrankenPHP, or DDEV; optional Pest, PHPUnit, PHP-CS-Fixer, PHPStan, API Platform, Doctrine ORM, Symfony Messenger

## Installation

Install or set up from the source-backed instructions:

In Claude Code, run: /plugin marketplace add dev-toolings/superpowers-symfony, then /plugin install superpowers-symfony@superpowers-symfony. For project-scoped installation, add the documented extraKnownMarketplaces and enabledPlugins entries to .claude/settings.json.
