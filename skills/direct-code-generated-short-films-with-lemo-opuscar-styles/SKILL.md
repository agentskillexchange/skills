# Run code-generated short-film workflows with Lemo-Opuscar

Use a Claude Code plugin to turn a story brief into a short film project built from reusable style prompts, frame-by-frame code rendering, narration, music, and ffmpeg assembly.

## Prerequisites

Claude Code, Node 20+, ffmpeg, Python 3.11+ or uv, and enough local disk/runtime capacity for frame rendering and video assembly

## Installation

Install or set up from the source-backed instructions:

Run claude plugin marketplace add lemomo-ai/lemo-opuscar, then claude plugin install lemo-opuscar@lemolab. Alternatively clone https://github.com/lemomo-ai/lemo-opuscar and run claude from the checkout.
