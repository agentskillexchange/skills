# Inspect Unreal Editor state and capture visual evidence with EngineWire

Connect an MCP agent to EngineWire, inspect the current Unreal Editor selection and viewport, and return screenshots with a bounded scene-state report.

## Prerequisites

Compatible Unreal Editor and EngineWire plugin; MCP client; project capability access; optional matching Node.js stdio proxy

## Installation

Install or set up from the source-backed instructions:

Follow the pinned README and upstream Quick Start. Install a compatible EngineWire release plugin in the project or from Fab, enable it and restart Unreal Editor. Fab 0.6.0 may need Native MCP Server enabled in project settings and another restart. Configure the local /mcp endpoint and project capability token in the client. Pair any stdio proxy version with the plugin. Inspect installed schemas first. No plugin installation or engine execution was tested.
