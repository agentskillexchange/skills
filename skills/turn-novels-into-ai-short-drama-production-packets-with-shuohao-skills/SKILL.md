# Turn novels into AI short-drama production packets with shuohao-skills

Use shuohao-skills to have coding agents turn a source novel into character bibles, adaptation outlines, art bibles, screenplays, and storyboards with deterministic quality gates.

## Prerequisites

Node >= 18; Claude Code or Codex for skill execution; Codex CLI optional for image generation via imagegen
