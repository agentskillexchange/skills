# Deploy LibreChat as a self-hosted agent workspace

Deploy LibreChat when an operator needs a self-hosted, multi-user agent workspace with model routing, MCP tools, skills, code execution, access controls, and audit-friendly administration.

## Prerequisites

LibreChat deployment, Docker or supported host, model provider credentials, optional MCP servers

## Installation

Install or set up from the source-backed instructions:

Follow the LibreChat deployment documentation for Docker or a supported host, configure authentication and providers, then enable Agents, MCP tools, Skills, permissions, and observability for the workspace.
