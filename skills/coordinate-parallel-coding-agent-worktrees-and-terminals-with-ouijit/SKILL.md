# Coordinate parallel coding-agent worktrees and terminals with Ouijit

Use Ouijit to manage parallel CLI coding-agent tasks with per-task git worktrees, integrated terminals, lifecycle hooks, and sandboxed sessions.

## Prerequisites

Ouijit desktop app or source build, Git, Node.js 20+ for source builds, Claude Code/Codex/Pi/OpenCode or another supported agent CLI, optional Lima VM or nono sandbox backend

## Installation

Install or set up from the source-backed instructions:

Download the latest macOS or Linux release from https://github.com/ouijit/ouijit/releases/latest, or build from source with git clone https://github.com/ouijit/ouijit.git && cd ouijit && npm install && npm start. Add a git project, create task cards, configure lifecycle hooks for the chosen agent CLI, and use Ouijit's terminals or the ouijit CLI to create, start, continue, review, and complete tasks.
