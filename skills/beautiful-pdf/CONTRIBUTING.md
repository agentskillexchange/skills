# Contributing

Issues and focused pull requests are welcome.

Before submitting:

1. keep the skill portable and provider-neutral;
2. remove credentials, private paths, private corpus examples, and project-specific identities;
3. add or update tests for behavior changes;
4. run the package tests and validate `SKILL.md`;
5. describe operational assumptions and limits honestly.

By contributing, you agree that your contribution is licensed under the MIT License.
