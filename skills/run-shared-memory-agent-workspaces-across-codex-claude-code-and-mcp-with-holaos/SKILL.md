# Run shared-memory agent workspaces across Codex, Claude Code, and MCP with holaOS

Coordinate multiple coding agents in one local-first workspace with shared memory, tools, files, browser access, and MCP-backed integrations.

## Prerequisites

holaOS desktop workspace, Node.js 24 and npm for OSS development setup, optional Codex or Claude Code agent, optional MCP integrations

## Installation

Install or set up from the source-backed instructions:

Clone `https://github.com/holaboss-ai/holaOS.git`, copy `apps/desktop/.env.example` to `apps/desktop/.env`, run `npm run desktop:install`, run `npm run desktop:prepare-runtime:local`, then start the desktop development workspace with `npm run desktop:dev`.
