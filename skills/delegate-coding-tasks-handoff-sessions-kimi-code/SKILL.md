# Delegate bounded coding tasks and hand off sessions with Kimi Code

Coordinate local Kimi Code tasks with structured CLI output, or discover the installed KAP interface to hand off and supervise repository sessions.

## Prerequisites

Kimi Code CLI; configured model provider; coordinating agent runtime; curl and jq for KAP discovery

## Installation

Install or set up from the source-backed instructions:

Install Kimi Code using the platform-specific instructions in the upstream README. For macOS/Linux, download and inspect https://code.kimi.com/kimi-code/install.sh before running the installer locally. Open a new shell and run kimi --version. Configure a supported provider through the documented local setup. Copy skills/use-kimi-code/SKILL.md from MoonshotAI/kimi-code into your host agent’s supported skill directory and follow its version-independent discovery steps. Confirm current flags with kimi --help. This intake installs nothing and performs no authentication.
