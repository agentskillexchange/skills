# Run cost-constrained local coding sessions with ClawCodex

Start ClawCodex as a local Python coding-agent CLI when a repository task needs Claude Code-style editing with provider setup, token compression, verification, and reviewable session controls.

## Prerequisites

Python 3.10+, Git, a configured model provider, and the ClawCodex CLI

## Installation

Install or set up from the source-backed instructions:

Install from the upstream script or source checkout, run `clawcodex login` to configure a provider, use `clawcodex doctor` or `clawcodex verify` to check the environment, then start `clawcodex` inside the target repository.
