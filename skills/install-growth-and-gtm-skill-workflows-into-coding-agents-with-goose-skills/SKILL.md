# Install growth and GTM skill workflows into coding agents with Goose Skills

Use Goose Skills to give Claude Code, Codex, Cursor, and similar coding agents reusable growth and go-to-market workflows for research, ads, social, content, lead generation, SEO, and scraping tasks.

## Prerequisites

GooseWorks CLI, npm/npx, Claude Code, Codex, Cursor, or another supported coding agent, and any task-specific provider credentials required by selected skills.

## Installation

Install or set up from the source-backed instructions:

Run npx gooseworks install --all to install GooseWorks skills for detected supported agents, or use the documented GooseWorks CLI options to search and install specific skills. After installation, ask the coding agent to use a named GooseWorks skill or /gooseworks workflow for the target growth or GTM task.
