# Coordinate multi-model coding squads with Vibe Squad

Use Vibe Squad to route a scoped development goal through a Markdown-defined coordinator, specialist roles, isolated git worktrees, native model CLIs, and independent review before integration.

## Prerequisites

Vibe Squad, tmux, fswatch, jq, curl, Python 3.13, uv, authenticated native CLIs for selected model families

## Installation

Install or set up from the source-backed instructions:

Clone `https://github.com/mtarcure/claude-vibe-squad`, run `uv sync`, install the reviewed local leak guard with `bash docs/install/install-pre-commit-hook.sh`, then run `bin/squad doctor` and `bin/squad up`.
