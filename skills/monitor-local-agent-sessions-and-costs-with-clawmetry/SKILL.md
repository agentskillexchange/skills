# Monitor local agent sessions and costs with ClawMetry

Use ClawMetry when an operator needs a local dashboard for agent sessions, token spend, tool calls, alerts, and governance across multiple runtimes.

## Prerequisites

Python 3.8+, clawmetry package, at least one supported local agent runtime, optional license or self-hosted configuration for paid runtime coverage

## Installation

Install or set up from the source-backed instructions:

Install with pip install clawmetry and run clawmetry. The dashboard opens locally at http://localhost:8900 and auto-detects supported local agent runtimes. Docker and one-line shell installer options are documented upstream.
